# crowdstrike_ioa_exclusion (Data Source)

Looks up a single IOA exclusion by ID or exact name. The lookup fails if no object or multiple objects match. Use an ID to disambiguate matches.

## API Scopes

The following API scopes are required:

- IOA Exclusions | Read


## Example Usage

```terraform
data "crowdstrike_ioa_exclusion" "by_id" {
  id = "11111111111111111111111111111111"
}

data "crowdstrike_ioa_exclusion" "by_name" {
  name = "Example exclusion"
}
```
