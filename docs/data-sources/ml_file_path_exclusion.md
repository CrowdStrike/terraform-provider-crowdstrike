# crowdstrike_ml_file_path_exclusion (Data Source)

Looks up a single ML file path exclusion by ID or exact pattern. The lookup fails if no object or multiple objects match. Use an ID to disambiguate matches.

## API Scopes

The following API scopes are required:

- Machine Learning Exclusions | Read


## Example Usage

```terraform
data "crowdstrike_ml_file_path_exclusion" "by_id" {
  id = "11111111111111111111111111111111"
}

data "crowdstrike_ml_file_path_exclusion" "by_pattern" {
  pattern = "/opt/example/cache/*"
}
```
