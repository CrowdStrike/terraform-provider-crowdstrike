# crowdstrike_custom_ioc (Data Source)

Looks up a single custom IOC by ID or by type and exact value. The lookup fails if no object or multiple objects match. Use an ID to disambiguate matches.

## API Scopes

The following API scopes are required:

- IOC Management | Read


## Example Usage

```terraform
data "crowdstrike_custom_ioc" "by_id" {
  id = "11111111111111111111111111111111"
}

data "crowdstrike_custom_ioc" "by_value" {
  type  = "domain"
  value = "sample.example.com"
}
```

## Schema

### Optional

- `id` (String) Unique identifier. Specify either `id` or both `type` and `value`.
- `type` (String) IOC type. Required with `value` when `id` is omitted.
- `value` (String) Exact, case-sensitive indicator value. Required with `type` when `id` is omitted.

### Read-Only

- `action` (String) The action on non-mobile platforms (`windows`, `mac`, `linux`), or null when it does not apply.
- `applied_globally` (Boolean) Whether the indicator is applied globally to all hosts.
- `created_by` (String) The user who created the IOC indicator.
- `created_on` (String) The timestamp when the IOC indicator was created.
- `description` (String) A description of the IOC indicator.
- `expiration` (String) The expiration date in RFC3339 format, or null if the indicator does not expire.
- `host_groups` (Set of String) Host group IDs that receive this indicator. Contains `["all"]` when applied globally.
- `mobile_action` (String) The action on mobile platforms (`ios`, `android`), or null when it does not apply.
- `modified_by` (String) The user who last modified the IOC indicator.
- `modified_on` (String) The timestamp when the IOC indicator was last modified.
- `platforms` (Set of String) The platforms this IOC indicator applies to. Valid values are: `windows`, `mac`, `linux`, `ios`, `android`. Hash types (`sha256`, `md5`) only support non-mobile platforms (`windows`, `mac`, `linux`); `all_subdomains` only supports mobile platforms (`ios`, `android`).
- `severity` (String) The severity level of the IOC indicator, if configured.
- `source` (String) The source of the IOC indicator.
- `tags` (Set of String) The tags attached to the IOC indicator.
