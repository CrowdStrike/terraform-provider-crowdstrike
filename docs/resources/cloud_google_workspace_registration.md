# crowdstrike_cloud_google_workspace_registration (Resource)

This resource manages the Google Workspace registration of a Google Cloud registration in Falcon Cloud Security. If the Google Cloud registration already has a Google Workspace registration that has no settings, for example one that was added in the Falcon console, the resource adopts and updates it. The resource gives the Workload Identity Federation (WIF) values that the Google Workspace Terraform module needs. When you destroy this resource, Falcon deletes the Google Workspace registration.

## API Scopes

The following API scopes are required:

- Cloud Security Google Cloud Registration | Read & Write


## Example Usage

```terraform
terraform {
  required_providers {
    crowdstrike = {
      source = "registry.terraform.io/crowdstrike/crowdstrike"
    }
  }
}

provider "crowdstrike" {
  cloud = "us-2"
}

resource "crowdstrike_cloud_google_workspace_registration" "example" {
  registration_id = "my-google-cloud-registration-id"
  customer_id     = "C01abc2de"
  organization_id = "123456789012"
}

output "google_workspace_registration" {
  value = crowdstrike_cloud_google_workspace_registration.example
}
```

## Schema

### Required

- `customer_id` (String) The Google Workspace customer ID, for example C01abc2de. Falcon cannot change it after the Google Workspace Terraform module sends its settings, so a change replaces the Google Workspace registration.
- `organization_id` (String) The ID of the Google Cloud organization of the Google Workspace. Must be numeric. Falcon refuses a change after the Google Workspace registration is complete.
- `registration_id` (String) The ID of the Google Cloud registration that has the Google Workspace registration. A change replaces the Google Workspace registration.

### Read-Only

- `id` (String) The Google Workspace registration ID.
- `service_account_id` (String) The account name that Falcon selects for the service account that the Google Workspace Terraform module creates. Google gives the service account a different, numeric unique ID.
- `wif_identity_source` (String) The identity source of the Workload Identity Federation (WIF) provider: aws-sts or gcp-oidc.
- `wif_pool_id` (String) The ID of the Workload Identity Federation (WIF) pool to create for the Google Workspace.
- `wif_provider_id` (String) The ID of the Workload Identity Federation (WIF) provider to create in the pool.

## Import

Import is supported using the following syntax:

```shell
# The Google Workspace registration of a Google Cloud registration can be imported by the Google Cloud registration ID.
terraform import crowdstrike_cloud_google_workspace_registration.example <gcp-registration-id>
```
