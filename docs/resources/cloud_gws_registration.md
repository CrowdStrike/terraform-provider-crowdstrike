# crowdstrike_cloud_gws_registration (Resource)

This resource adopts the Google Workspace registration of a Google Cloud registration in Falcon Cloud Security. Add the Google Workspace to the Google Cloud registration in the Falcon console first: this resource does not create it. The resource gives the Workload Identity Federation (WIF) values that the Google Workspace Terraform module needs. When you destroy this resource, Falcon deletes the Google Workspace registration.

## API Scopes

The following API scopes are required:

- Cloud Security Google Cloud Registration | Read & Write


## Example Usage

```terraform
terraform {
  required_providers {
    crowdstrike = {
      source = "registry.terraform.io/crowdstrike/crowdstrike"
    }
  }
}

provider "crowdstrike" {
  cloud = "us-2"
}

# Add the Google Workspace to the Google Cloud registration in the Falcon console first.
resource "crowdstrike_cloud_gws_registration" "example" {
  gcp_registration_id = "my-google-cloud-registration-id"
}

output "gws_registration" {
  value = crowdstrike_cloud_gws_registration.example
}
```

## Schema

### Required

- `gcp_registration_id` (String) The ID of the Google Cloud registration that has the Google Workspace registration. You cannot change it: destroy this resource first.

### Read-Only

- `id` (String) The Google Workspace registration ID.
- `service_account_id` (String) The ID of the service account to create for the Google Workspace.
- `wif_identity_source` (String) The identity source of the Workload Identity Federation (WIF) provider: aws-sts or gcp-oidc.
- `wif_pool_id` (String) The ID of the Workload Identity Federation (WIF) pool to create for the Google Workspace.
- `wif_provider_id` (String) The ID of the Workload Identity Federation (WIF) provider to create in the pool.

## Import

Import is supported using the following syntax:

```shell
# The Google Workspace registration of a Google Cloud registration can be imported by the Google Cloud registration ID.
terraform import crowdstrike_cloud_gws_registration.example <gcp-registration-id>
```
