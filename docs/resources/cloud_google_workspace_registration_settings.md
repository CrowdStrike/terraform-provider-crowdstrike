# crowdstrike_cloud_google_workspace_registration_settings (Resource)

This resource sends the output of the Google Workspace Terraform module to the Google Workspace registration of a Google Cloud registration in Falcon Cloud Security. Falcon then starts a health check of the Google Workspace registration. When you destroy this resource, Falcon clears these values.

## API Scopes

The following API scopes are required:

- Cloud Security Google Cloud Registration | Read & Write


## Example Usage

```terraform
terraform {
  required_providers {
    crowdstrike = {
      source = "registry.terraform.io/crowdstrike/crowdstrike"
    }
  }
}

provider "crowdstrike" {
  cloud = "us-2"
}

resource "crowdstrike_cloud_gws_registration" "workspace" {
  gcp_registration_id = "my-google-cloud-registration-id"
}

# The four values are the outputs of the Google Workspace Terraform module.
resource "crowdstrike_cloud_google_workspace_registration_settings" "example" {
  registration_id           = crowdstrike_cloud_gws_registration.workspace.gcp_registration_id
  service_account_email     = "csgws-1a2b3c4d5e6@my-wif-project-id.iam.gserviceaccount.com"
  service_account_unique_id = "123456789012345678901"
  wif_principal             = "principal://iam.googleapis.com/projects/123456789012/locations/global/workloadIdentityPools/my-pool/subject/my-subject/my-google-workspace-registration-id"
  wif_project_number        = "123456789012"
}
```

## Schema

### Required

- `registration_id` (String) The ID of the Google Cloud registration that has the Google Workspace registration.
- `service_account_email` (String) The email of the service account that the Google Workspace Terraform module created.
- `service_account_unique_id` (String) The numeric unique ID that Google gave to the service account that the Google Workspace Terraform module created. It is not the service_account_id of the Google Workspace registration, which is the account name that Falcon selects.
- `wif_principal` (String) The Workload Identity Federation (WIF) principal that the Google Workspace Terraform module created.
- `wif_project_number` (String) The number of the Google Cloud project that has the Workload Identity Federation (WIF) pool.

### Read-Only

- `workspace_registration_id` (String) The ID of the Google Workspace registration that has the settings.

## Import

Import is supported using the following syntax:

```shell
# The Google Workspace registration settings can be imported by the Google Cloud registration ID.
terraform import crowdstrike_cloud_google_workspace_registration_settings.example <gcp-registration-id>
```
