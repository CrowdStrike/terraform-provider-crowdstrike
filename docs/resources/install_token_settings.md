# crowdstrike_install_token_settings (Resource)

Manages the installation token settings of a CID, including whether sensor installations require an installation token (Require Tokens). A CID has a single set of these settings, so manage them with at most one instance of this resource per CID. Destroying this resource sets `tokens_required` to `false` and leaves `max_active_tokens` unchanged.

## API Scopes

The following API scopes are required:

- Installation Tokens | Read
- Installation Tokens Settings | Write


## Example Usage

```terraform
terraform {
  required_providers {
    crowdstrike = {
      source = "registry.terraform.io/crowdstrike/crowdstrike"
    }
  }
}

provider "crowdstrike" {
  cloud = "us-2"
}

# Require a valid installation token for every sensor installation in the CID.
# Create an installation token before turning this on so existing deployments
# have a token to use.
resource "crowdstrike_install_token" "deployment" {
  name = "Production Deployment Token"
}

resource "crowdstrike_install_token_settings" "example" {
  tokens_required   = true
  max_active_tokens = 50

  depends_on = [crowdstrike_install_token.deployment]
}
```

## Schema

### Required

- `tokens_required` (Boolean) Whether sensor installations in the CID must provide a valid installation token.

### Optional

- `max_active_tokens` (Number) The maximum number of active installation tokens allowed in the CID. If not set, the current limit is kept.

- `id` (String) Identifier for the installation token settings. A CID has a single set of these settings, so this is always `install_token_settings`.
